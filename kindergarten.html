Южное Медведково, Москва

Доступность детских садов: буфер против реальности

Суть проекта

Общепринятым методом оценки доступности объектов социальной инфраструктуры является построение 300-метровых буферов от центроидов дошкольных учреждений и определение числа жилых домов, попадающих в зону такого буфера. Недостатком данного метода является нечувствительность буфера к реальным преградам: дорогам, заборам и перепадам рельефа. Из-за этого возникает необходимость оценить доступность альтернативным способом: через построение сетевых изохрон пятиминутной пешей доступности — и сравнить результат с нормативным методом.

Методология

Данные

Граница района и жилые дома получены из OpenStreetMap с помощью библиотеки OSMnx. Для анализа взяты детские сады, находящиеся в пределах района Южное Медведково, а также в соседних районах — в случае, если они попадают в зону пешеходной доступности. Вокруг административной границы построен буфер 1 км в метрической проекции (UTM37), чтобы пешеходная сеть не обрывалась искусственно по административной черте; там, где в OSM отсутствовали внутридворовые проходы, сеть дополнена вручную в QGIS.

Построение зон доступности

Сначала для каждого детского сада были построены простые буферы радиусом 300 м от центроидов зданий (GeoPandas/Shapely).

Затем зоны доступности были построены повторно — уже по сети пешеходных путей. Для каждого дома и сада в граф добавлен собственный узел точно в центроиде здания, соединённый с ближайшим узлом сети двумя рёбрами реальной длины. Изохроны построены для порога 5 минут ходьбы при средней скорости 4 км/ч (~333 м по сети): сетевые расстояния (алгоритм Дейкстры, NetworkX) интерполированы вдоль рёбер каждые 10 м, переведены в непрерывную растровую поверхность (SciPy) и затем — в полигон (Rasterio).

Оценка обеспеченности

Для каждого из двух методов обеспеченность рассчитывалась по одной и той же методике:

  1. Население каждого дома распределяется между доступными садами пропорционально их вместимости
    N_x_iYe = (X_i × Y_e) / ΣY_e
  2. Для каждого сада считается суммарная нагрузка по этому распределению
    L_Ye = Σ N_x_iYe
  3. Определяется спрос на одно место в каждом саду
    S_e = L_Ye / Y_e
  4. Выполняется обратное распределение — пропорционально величине, обратной спросу (Z_e = 1 / S_e)
    N_x_iZe = (X_i × Z_e) / ΣZ_e
  5. Для каждого сада считается нагрузка по второму распределению
    L_Ze = Σ N_x_iZe
  6. Два варианта распределения усредняются
    N_x_iYeZe = (N_x_iYe + N_x_iZe) / 2
  7. Вычисляется итоговая усреднённая нагрузка на каждый сад
    L_Ve = Σ N_x_iYeZe
  8. Определяется обеспеченность на каждом саду
    P_e = Y_e / L_Ve
  9. Обеспеченность каждого дома — среднее по всем доступным ему садам
    P_i = среднее(P_e)
  10. Итоговая обеспеченность района — средневзвешенная по населению (дома без доступа учтены отдельно, а не подмешаны в среднее)
    P_св = Σ(P_i × X_i) / ΣX_i

где X_i — население дома дошкольного возраста, Y_e — вместимость сада.

Результаты

Средняя обеспеченность района ожидаемо почти не изменилась (0.718 по буферу против 0.709 по сети), однако значительно изменилось расчётное распределение спроса. По буферу без доступа к саду — 14 домов из 176 (8%, 394 жителя). По сети — 90 домов, 51% района, 2506 жителей (39%). Буфер занижает число домов без доступа в 6.4 раза и завышает нагрузку на детские сады: среди домов с подтверждённым сетевым доступом обеспеченность оказалась бы на 52% выше, чем показывал буфер, а число перегруженных садов — вдвое меньше.
